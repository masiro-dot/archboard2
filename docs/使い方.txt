ArchBoard Phase 0 ― はじめにお読みください
================================================

■ 中身
  ArchBoard.html ......................... アプリ本体（ダブルクリックで開く）
  addon/archboard_exporter-0.1.0.zip ..... Blender アドオン
  sample/sample_house.blend .............. 架空のサンプル住宅（Blender ファイル）
  sample/archboard/ ...................... 上のモデルを書き出したもの（model.glb / manifest.json）

  ※ 案件データは一切含まれていません。サンプルはすべて架空です。
  ※ インターネット接続は不要です。データは PC の外に出ません。


■ 1. まずアプリだけ試す（5 分）
  1) ArchBoard.html を Chrome または Edge で開く
     （右クリック →「プログラムから開く」→ Chrome / Edge）
  2)「サンプルで試す」を押す
  3) 左の「シート」を切り替えて、3 枚の見本ボードを見る
  4) 何もない所を左ドラッグで視点を回す → 文字や矢印が部材を指し続けることを確認


■ 2. 注釈を付ける
  ツールバー（用紙の上）またはキーボードで切り替えます。

  ラベル (L)  部材をクリック → 引出線付きの文字。右パネルで文字を編集
  矢印  (A)  始点の部材 → 終点の部材をクリック。破線にすると動線向き
  寸法  (D)  2 点をクリック。角の近くでは頂点に吸い付きます（Alt で吸着なし）
             寸法の数値はモデルから自動計算され、手で書き換えられません
  文字  (T)  用紙の好きな位置をクリック（タイトルや説明文）
  選択  (V)  注釈をドラッグで移動。寸法は数値をドラッグすると離れを調整

  ダブルクリック ... 文字の編集欄へ移動
  Delete ........... 選択中の注釈を削除
  Ctrl+Z / Ctrl+Y .. 元に戻す / やり直し
  Ctrl+S ........... 保存
  PageUp / Down .... シート切り替え
  Esc .............. ツールを中止


■ 3. シートの設定（右パネル）
  表示スタイル ... 白模型 / マテリアル / 線画
  断面 ........... 水平（平面図）・東西・南北で切断。切り口は黒く塗られます
  カメラ ......... 焦点距離、垂直補正（2点透視）、平行投影と縮尺（1/100 など）
  カメラを固定 ... 構図を決めたら誤操作防止にチェック


■ 4. Blender アドオンの入れ方
  1) Blender 5.2 を起動
  2) 編集 → プリファレンス → アドオン
  3) 右上の「∨」→「ディスクからインストール」→ archboard_exporter-0.1.0.zip を選ぶ
  4) 3D ビューで N キー → 右のサイドバーに「ArchBoard」タブが出ます

  ・「サンプル建物を生成」 ... 動作確認用の架空の住宅を作ります
  ・「ArchBoard 用に書き出し」 ... model.glb と manifest.json を書き出します
    （書き出し先の初期値は .blend と同じ場所の archboard フォルダ）

  ※ 書き出しは形状を一切変更しません。モディファイアは適用した見た目で出力されます。


■ 5. 自分のモデルで使う流れ
  1) Blender でオブジェクト名を「種別_階_名前」にする
       例) WALL_1F_N   WIN_2F_S   SLAB_2F   COL_1F_01   ROOF_Main
       種別: SLAB 床 / WALL 壁 / COL 柱 / BEAM 梁 / ROOF 屋根 / WIN 窓 / DOOR 扉
             STAIR 階段 / RAIL 手摺 / LAND 外構 / TREE 樹木 / CTX 周辺 / FURN 家具
     カスタムプロパティ label_ja に日本語名を入れると、ラベルの初期文字になります
  2) Blender でカメラを置く（名前は CAM_01_外観 など。シートの元になります）
  3)「ArchBoard 用に書き出し」
  4) ArchBoard.html で「フォルダを開く」→ 書き出した archboard フォルダを選ぶ
     （初回だけ、フォルダの読み書きを許可する確認が出ます）
  5) 保存すると、同じフォルダに project.json ができます

  Cinema 4D のモデルは FBX で書き出して Blender に読み込んでください。


■ 6. 設計変更があったとき
  1) Blender でモデルを修正 → もう一度「ArchBoard 用に書き出し」
  2) ArchBoard で「モデル更新を確認」
  3) 変わった部材（オレンジ）・追加（緑）・削除（一覧）が表示されます
     削除された部材を指していた注釈は赤い「要確認」になります
     → 右パネルの「付け替える」で別の部材を指し直せます


■ 7. 書き出し（右上の「書き出し」）
  合成 PNG 150dpi ... 確認・メール用
  合成 PNG 300dpi ... A3 印刷用
  SVG ............... 文字・矢印がベクターのまま。Illustrator 等で文字を後から直せます
  Photoshop 用 ...... 3D 画像と注釈（透明背景）の 2 枚。レイヤーとして重ねて使えます
  全シート .......... 冊子用に全ページを一括で

  フォルダから開いた場合は、書き出したファイルはそのフォルダの exports に入ります。
  サンプルなどフォルダ以外の場合はダウンロードされます
  （複数ファイルのときは「複数ファイルのダウンロードを許可」を選んでください）。


■ 8. 形状ロック（右上の緑の表示）
  読み込んだ 3D を、Blender が書き出した記録と部材ごとに照合しています。
  「41/41 一致」のように全数が一致していれば、形状は Blender のままです。
  書き出しのたびにも再確認し、一致しなければ書き出しを止めます。
  クリックすると詳細（ハッシュ値・書き出し日時など）が見られます。


■ USB / GitHub で持ち運ぶとき
  ArchBoard.html と、案件ごとの archboard フォルダを一緒に持ち運べば、
  Chrome / Edge がある PC ならどこでも開けます。インストールは不要です。
